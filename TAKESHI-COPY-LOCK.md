| Request | May change | Must not change |

| Improve the mobile layout | CSS, spacing, crop, breakpoints | Paragraphs, headings, CTAs |
| Make the website more modern | Visual implementation | Messaging |

| Accessibility | Focus, contrast treatment, alt **if** still descriptive of the same image | Brand sentences rewritten for “simplicity” |
| Image work | Photographs, opacity, layout | Captions that invent proof; body copy |

If layout, SEO, or accessibility conflicts with approved copy:

> **Preserve the approved copy and report the conflict.**

Do not shorten, split, or “clarify” locked sentences to make a layout work unless a copy revision is authorized.
